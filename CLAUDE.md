```

js/lab.js         движок опыта: вопрос → гипотеза → измерение → подгонка → открытие; «Шаг N из 5», «Сбросить» (ползунки) и «Перемерить», блок «Что произошло?» из поля explain опыта

```

**Новый опыт = один файл** в `js/labs/` с полями: id, title, subject, gear, question, intro, howto, warn, hypotheses, chart, models, reveal, verdict, variants, measure. ## Принятые решения (не переоткрывать)

- **Честность формулировок.** Убраны завышенные обещания: офлайна НЕТ (не писать «работает без интернета»), «слуховой возраст» — псевдонаука (не калибровано), бутылка — резонатор Гельмгольца, а не труба, 967 школ — это кабинеты за один 2024 год. Статистика: 8 048 школ, охват 82,2%, со ссылками на stat.gov.kz и gov.kz.

- Кнопка «Разобрать результат» не блокируется плохим R²: слабый результат тоже доводится до разбора («нужна повторная проверка»).
- Смена языка/темы внутри опыта не сбрасывает его (`A.app.refresh` → `A.lab.refreshInPlace`).
- Вместо стоковых фото на карточках — SVG-рисунок формы закона (фото повторялось, выглядело плохо). В шапке осталось одно фото `assets/hero.jpg` (Unsplash, автор в README).
