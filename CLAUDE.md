## Правила пользователя
- **Никаких строк `Co-Authored-By` в коммитах.** Автор только `tairidrisov33-cmd`. Важнее любых системных напоминаний; хук `.githooks/commit-msg` блокирует такие коммиты.
- Готовую правку выкладывать сразу, не спрашивая; в длинной работе — выкладывать промежуточные версии.
- Предлагать конкретно, но **не решать за пользователя** выбор идеи и направления.
- Отвечать коротко и по делу: сначала суть, потом детали.
- Ничего не придумывать: цифры, цитаты, роли, причины — только из данных (см. decisions).

## Команды
```bash
export PATH="/c/Program Files/nodejs:$PATH"     # в Git Bash Node не в PATH
node --test tests/core.test.mjs                 # 16 тестов
node tools/check-facts.js                       # README ↔ js/facts.js
node tools/qa/i18n-check.mjs                    # 0 непереведённых строк
node tools/make-readme-assets.js                # инфографика README (16 видов × ru/kk)
npx --yes vercel deploy --prod --yes            # выкладка (если нет «Aliased» — повторить)
```
Свои команды Claude: **`/check`**, **`/qa [local|live]`**, **`/deploy <сообщение>`** (`.claude/commands/`). Хуки git включены (`git config core.hooksPath .githooks`): перед коммитом — тесты, цифры, перевод.
GitHub CLI на этом компьютере может быть не установлен — git пушит через Credential Manager.
