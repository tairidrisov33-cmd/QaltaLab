## Архитектура

Без сборщика и зависимостей: обычные `<script defer>` в `index.html`, пространство имён `A`.

```
js/i18n.js        словарь ru→kk (ключ = русский текст), A.i18n.t / A.i18n.fmt
js/i18n-labs.js   перевод строк опытов (дополняет словарь)
js/utils.js       A.h() — построение разметки с переводом; A.u — хелперы
js/icons.js       SVG-иконки A.icon(name)
js/store.js       прогресс в localStorage
js/fit.js         R² (может быть отрицательным — это честно, в UI показывается «<0%»)
js/chart.js       график точек + кривая + «призрак» прошлой серии
js/hero.js        демо-график на главной (явно подписан «демо»)
js/lab.js         движок опыта: вопрос → гипотеза → измерение → подгонка → открытие
                  + «А если попробовать иначе?» — повтор в других условиях и сравнение серий
js/labs/*.js      девять опытов, по файлу на опыт
js/app.js         главная-лендинг, тема, язык, рисунки законов на карточках (labArt)
tests/            тесты на Node (в выкладку не идут, см. .vercelignore)
```

**Новый опыт = один файл** в `js/labs/` с полями: id, title, subject, gear, question, intro, howto, warn, hypotheses, chart, models, reveal, verdict, variants, measure. Подключить `<script defer>` в index.html, добавить значок в `LAB_ICON` и функцию формы в `ART` (app.js), порядок в списке опытов, и **перевести все строки** в `i18n-labs.js`.

## Принятые решения (не переоткрывать)

- **Честность формулировок.** Убраны завышенные обещания: офлайна НЕТ (не писать «работает без интернета»), «слуховой возраст» — псевдонаука (не калибровано), бутылка — резонатор Гельмгольца, а не труба, 967 школ — это кабинеты за один 2024 год. Статистика: 8 048 школ, охват 82,2%, со ссылками на stat.gov.kz и gov.kz.
- **Громкость в опыте со слухом ограничена** `MAX_GAIN = 0.08` — безопасность слуха.
- Кнопка «Разобрать результат» не блокируется плохим R²: слабый результат тоже доводится до разбора («нужна повторная проверка»).
- Смена языка/темы внутри опыта не сбрасывает его (`A.app.refresh` → `A.lab.refreshInPlace`).
- Вместо стоковых фото на карточках — SVG-рисунок формы закона (фото повторялось, выглядело плохо). В шапке осталось одно фото `assets/hero.jpg` (Unsplash, автор в README).
- Палитра зелёно-оливковая, заголовки засечным, текст Manrope, числа JetBrains Mono.
- Знак (27.09, лупу пользователь забраковал): оси графика, кривая закона и три точки данных на зелёном #426D4F. Значки пересобирает mkicons.js (черновики сессии), адреса значков с ?v=2 — при смене поднять. `icons/icon.svg`, `icon-192/512.png`, `apple-touch-icon.png`, `og.png` (1200×630).
