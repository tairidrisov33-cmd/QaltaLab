# STEM Pocket Lab · QaltaLab

**Зертхана қалтаңда — лаборатория в кармане.**

Проект хакатона **WIT Teens Challenge 2026**, кейс «STEM без сложного оборудования».

## Идея

Школьнику из небольшого города негде поставить опыт: лаборатории нет, оборудования нет.
Но микрофон, камера, динамик и акселерометр в его телефоне — это настоящие измерительные
приборы. Оборудование не нужно покупать: оно уже куплено.

В приложении **нет ни одного чужого числа**. Каждая цифра на экране измерена самим
школьником. Формула не показывается: ученик собирает свои точки, подбирает под них кривую
и только тогда открывает закон — вместе с именем учёного и годом открытия.

## Как устроен опыт

1. **Вопрос** — что мы вообще хотим узнать
2. **Гипотеза** — предсказание записывается ДО опыта
3. **Опыт** — телефон измеряет, точки ложатся на график
4. **Подгонка** — ученик сам подбирает зависимость
5. **Открытие** — карточка закона и разбор гипотезы

## Опыты

| Опыт | Чем меряет | Что открывает |
|---|---|---|
| Твой слух | динамик | порог слышимости и «слуховой возраст» |
| Скорость мысли | экран | закон Хика |
| Высота звука | микрофон | зависимость частоты от длины столба воздуха |

## Технологии

Сайт без сборщика: обычные HTML, CSS и JavaScript, никаких зависимостей.
Web Audio API для генерации и анализа звука, Canvas для графиков, localStorage для прогресса.
Работает на телефоне, ноутбуке и школьном ПК, в том числе без интернета после первой загрузки.

## Запуск

Открыть `index.html` или поднять любой статический сервер в корне проекта.
