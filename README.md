## Кратко

<img src="docs/readme/summary-ru.svg" width="100%" alt="Проблема, решение и результат">

- **Проблема.** Базового уровня по естественным наукам в Казахстане достигают только **55%** пятнадцатилетних, в среднем по ОЭСР — **76%**. Науку учат как формулу на доске.
- **Решение.** QaltaLab превращает обычный телефон в прибор: микрофон, камера и касания измеряют настоящий опыт, а школьник сам выводит закон по **своим** точкам.
- **Чем новое.** Рисунок-предсказание до опыта против своих данных, «Физика домбры» с законом струны и общий график класса по QR-коду.
- **Результат.** Пилотный тест, **n = 29**: удобство с телефона **4,83 / 5**, интерактивные опыты отметили **96,6%**.
- **Где.** В браузере, без установки и аккаунта, на русском и казахском: [qaltalab.site](https://qaltalab.site).

## Проблема

<img src="docs/readme/problem-ru.svg" width="100%" alt="Проблема в цифрах">

В Казахстане **8 048** общеобразовательных школ ([Бюро национальной статистики, 31.08.2026](https://stat.gov.kz/ru/news/bolee-8-tysyach-shkol-kazakhstana-nachali-novyy-uchebnyy-god/)). По итогам **2024** года закуплено **1 621** современный предметный кабинет для **967** школ: **601** сельская и **366** городских ([Министерство просвещения РК](https://www.gov.kz/memleket/entities/edu/documents/details/836066)). Оснащение идёт, но кабинет есть не всегда и не у каждого — особенно дома, когда хочется попробовать самому.

По данным PISA 2022, базового уровня по естественным наукам в Казахстане достигают только **55%** пятнадцатилетних — в среднем по странам ОЭСР **76%** ([ОЭСР, PISA 2022](https://www.oecd.org/en/publications/pisa-2022-results-volume-i-and-ii-country-notes_ed6fbcc5-en/kazakhstan_8c403c04-en.html)). Почти каждый второй школьник знает науку как формулу на доске, а не как то, что можно измерить самому.

## Решение

<img src="docs/readme/method-ru.svg" width="100%" alt="Пять шагов научного метода">

Каждый опыт идёт по пяти шагам научного метода: вопрос → гипотеза → измерение → график → открытие. Формулы на экране нет: ученик двигает ползунки, пока кривая не ляжет на его точки, а `R²` честно показывает, насколько модель описывает данные — даже когда результат слабый. На экране результата — что ты обнаружил, почему так произошло, сам закон и новый вопрос «а если попробовать иначе?».

## Новизна: нарисуй предсказание

<img src="docs/readme/predict-ru.svg" width="100%" alt="Рисунок-предсказание против настоящих точек">

До измерения ученик пальцем рисует, каким ожидает график. После опыта рисунок ложится пунктиром поверх настоящих точек, а карточка «Предсказание и реальность» показывает средний промах и место, где интуиция ошиблась сильнее всего. Это метод «Предскажи — проверь — объясни» (White & Gunstone, 1992), только не словами, а формой кривой. Разницу между рисунком и данными разбирает и Zerde AI.

## Физика домбры

<img src="docs/readme/dombra-ru.svg" width="100%" alt="Физика домбры: закон струны">

Опыт, сделанный для школ Казахстана. Ученик зажимает струну на разных ладах, линейкой меряет длину звучащей части, а телефон слушает щипок и находит основной тон **по гармоникам** `f`, `2f`, `3f`: у щипка второй обертон часто громче основного тона, и простой поиск самого громкого пика ошибся бы на октаву. Точки ложатся на гиперболу `f = a / L` — струна вдвое короче звучит на октаву выше. Это закон Мерсенна (1636), а лады как отношения длин струны описывал ещё Аль-Фараби в «Большой книге о музыке». Нет домбры — подойдёт гитара или натянутая резинка.

## Общий график класса

<img src="docs/readme/classboard-ru.svg" width="100%" alt="Общий график класса">

Работает с любым опытом. Учитель нажимает «Провести с классом» и получает код, QR-код и короткую ссылку `qaltalab.site/c/КОД`. Ученики проходят опыт на своих телефонах, а на экране класса для проектора точки всех учеников ложатся на один график; кривую по всем точкам сайт подбирает сам. Точки далеко от общей кривой подсвечиваются — повод обсудить ошибки измерения. Данные класса скачиваются в CSV для Excel. Имён нет: хранятся только код класса, id опыта и числа точек.

## Пилотное тестирование

<img src="docs/readme/pilot-ru.svg" width="100%" alt="Пилотное тестирование, n = 29">

Анкета после опыта, **n = 29**. Это самооценка участников, а не исследование успеваемости; возраст анкета не фиксировала.

| Вопрос | Ответы |
|---|---|
| Удобство с телефона | **4,83 / 5** · 5 из 5 — 24/29 (82,8%) · 4 или 5 — 29/29 |
| Общая оценка | **4,79 / 5** · 5 из 5 — 23/29 (79,3%) · 4 или 5 — 29/29 |
| Формат «попробуй сам — сразу увидь результат» помогает понимать STEM | «да» 21/29 (72,4%) · «скорее да» 8/29 (27,6%) · вместе **100%** |
| Хотели бы использовать на уроках или дома | «да» 22/29 (**75,9%**) · «возможно» 7/29 (24,1%) · «нет» 0 |
| Поняли, что такое QaltaLab, с первого раза | «да» 22/29 (75,9%) · «частично» 7/29 (24,1%) · «нет» 0 |
| Понравились интерактивные эксперименты | 28/29 (**96,6%**) |

**Что мы изменили по итогам.** 24,1% участников поняли продукт с первого раза только частично, поэтому первый экран переписан: сразу видно, что телефон становится прибором, а ученик получает собственные данные. Открытый комментарий оставили 9 человек: 8 — положительные, один предложил добавить больше игровых элементов.

## Технологии

<img src="docs/readme/pipeline-ru.svg" width="100%" alt="От датчика до закона">

<img src="docs/readme/phone-ru.svg" width="100%" alt="Возможности телефона, которые используют опыты">

| Что выбрали | Почему |
|---|---|
| Чистый JavaScript без фреймворков | весь код — около 160 КБ при загрузке: сайт быстро открывается на слабом школьном телефоне |
| Датчики через API браузера | `getUserMedia` и Web Audio: ничего не нужно устанавливать, опыт открывается по ссылке |
| Обработка сигнала на устройстве | БПФ, поиск тона по гармоникам, медианы против случайных промахов; сырой звук и видео не покидают телефон |
| Подгонка модели и честный `R²` | ученик сам двигает параметры; на экране класса кривая подбирается автоматически, выбросы ищутся по медиане отклонений |
| Zerde AI на открытых моделях (Groq) | на сервер уходят только числа опыта и рисунок-предсказание; ответ за секунды, ключ хранится на сервере |
| Supabase для общего графика класса | таблицы закрыты, запись и чтение — только через функции с проверкой ввода и лимитами |
| Vercel и GitHub | постоянная ссылка и HTTPS — без него браузер не даст доступ к микрофону и камере; код открыт |

В каждом опыте есть блок «Под капотом» — путь от датчика до точки на графике. В «Бутылочном оркестре» и «Физике домбры» виден живой спектр звука с отметкой найденного тона. QR-код на экране класса сделан собственным генератором, без сторонних библиотек.

**Zerde AI** — наставник внутри опыта. Кнопка «Разобрать мой результат» отправляет числа этого опыта и получает разбор из четырёх частей: что ты обнаружил, почему так произошло, что говорят твои данные (включая сравнение с рисунком-предсказанием), что попробовать дальше. Слабые данные Zerde так и называет слабыми. В правом нижнем углу есть чат, который отвечает только про опыты QaltaLab и научный метод.

## Качество

<img src="docs/readme/quality-ru.svg" width="100%" alt="Качество: Lighthouse и тесты">

- **16** автотестов: логика опытов, поиск тона по гармоникам, рисунок-предсказание, автоподгонка, QR-код, выбросы.
- Сквозная проверка в браузере: все 10 опытов от вопроса до сравнения серий, на двух языках, на телефоне и компьютере, в светлой и тёмной теме — **0** ошибок в консоли.
- Скрипт сверяет каждую цифру этого README с единым файлом фактов сайта (`js/facts.js`).

## Архитектура и приватность

<img src="docs/readme/arch-ru.svg" width="100%" alt="Архитектура QaltaLab">

- Измерения и подгонка модели выполняются в браузере. Без Zerde и без класса данные не покидают устройство.
- При разборе результата на `/api/zerde` уходят числа опыта: точки, `R²`, параметры модели, итог гипотезы и значения рисунка-предсказания в тех же точках. В чате — вопрос, до шести последних сообщений и числовой контекст открытого опыта.
- В общем графике класса на `/api/class` уходят только код класса, id опыта и числа точек.
- Ключи хранятся только в переменных окружения сервера. Сервер проверяет формат, ограничивает размер и частоту запросов. Имён и аккаунтов нет.

## Масштаб и развитие

<img src="docs/readme/scale-ru.svg" width="100%" alt="Почему это масштабируется">

## Ограничения

- Результат зависит от устройства: микрофона, динамика, камеры, экрана, а также от шума и освещения. Поэтому QaltaLab показывает `R²` и честно говорит, когда данных мало.
- «Твой слух» и «Пульс камерой» — образовательные опыты, **не медицинская диагностика**.
- Нужен интернет; разрешения на камеру и микрофон во встроенных браузерах мессенджеров часто отключены.
- Пилотная выборка небольшая (n = 29).

## Қысқаша

<img src="docs/readme/summary-kk.svg" width="100%" alt="Мәселе, шешім және нәтиже">

- **Мәселе.** Қазақстанда жаратылыстану ғылымдары бойынша базалық деңгейге он бес жастағылардың тек **55%**-ы жетеді, ЭЫДҰ бойынша орта есеппен — **76%**. Ғылымды тақтадағы формула ретінде оқытады.

## Мәселе

<img src="docs/readme/problem-kk.svg" width="100%" alt="Мәселе сандармен">

Қазақстанда **8 048** жалпы білім беретін мектеп бар ([Ұлттық статистика бюросы, 31.08.2026](https://stat.gov.kz/ru/news/bolee-8-tysyach-shkol-kazakhstana-nachali-novyy-uchebnyy-god/)). **2024** жылдың қорытындысы бойынша **967** мектепке **1 621** заманауи пән кабинеті сатып алынды: оның **601**-і ауыл мектебі, **366**-сы қала мектебі ([ҚР Оқу-ағарту министрлігі](https://www.gov.kz/memleket/entities/edu/documents/details/836066)). Жабдықтау жүріп жатыр, бірақ кабинет әрдайым және әркімде бола бермейді — әсіресе үйде, бір нәрсені өзің байқап көргің келгенде.

PISA 2022 деректері бойынша Қазақстанда жаратылыстану ғылымдары бойынша базалық деңгейге он бес жастағылардың тек **55%**-ы жетеді — ЭЫДҰ елдерінде орта есеппен **76%** ([ЭЫДҰ, PISA 2022](https://www.oecd.org/en/publications/pisa-2022-results-volume-i-and-ii-country-notes_ed6fbcc5-en/kazakhstan_8c403c04-en.html)). Әрбір екінші дерлік оқушы ғылымды өзі өлшей алатын нәрсе ретінде емес, тақтадағы формула ретінде біледі.

## Шешім

<img src="docs/readme/method-kk.svg" width="100%" alt="Ғылыми әдістің бес қадамы">

Әр тәжірибе ғылыми әдістің бес қадамынан өтеді: сұрақ → болжам → өлшеу → график → жаңалық. Экранда формула жоқ: оқушы қисық нүктелеріне түскенше жүгірткілерді жылжытады, ал `R²` модельдің деректерді қаншалықты сипаттайтынын ашық көрсетеді — нәтиже әлсіз болса да. Нәтиже экранында — сен не таптың, неге олай болды, заңның өзі және «басқаша жасап көрсе ше?» деген жаңа сұрақ.

## Жаңалық: болжауды сал

<img src="docs/readme/predict-kk.svg" width="100%" alt="Сурет-болжау нақты нүктелерге қарсы">

Өлшеуге дейін оқушы графиктің қандай болатынын саусағымен салады. Тәжірибеден кейін сурет нақты нүктелердің үстіне үзік сызықпен түседі, ал «Болжау және шындық» карточкасы орташа айырманы және түйсік ең көп қателескен жерді көрсетеді. Бұл — «Болжа — тексер — түсіндір» әдісі (White & Gunstone, 1992), тек сөзбен емес, қисықтың пішінімен. Сурет пен деректердің айырмасын Zerde AI да талдайды.

## Домбыра физикасы

<img src="docs/readme/dombra-kk.svg" width="100%" alt="Домбыра физикасы: ішек заңы">

Қазақстан мектептері үшін жасалған тәжірибе. Оқушы ішекті әртүрлі пернелерде басып, дыбысталатын бөліктің ұзындығын сызғышпен өлшейді, ал телефон шертуді тыңдап, негізгі тонды `f`, `2f`, `3f` **гармоникалары бойынша** табады: шертуде екінші обертон жиі негізгі тоннан қаттырақ, ал ең қатты шыңды жай іздеу октаваға қателесер еді. Нүктелер `f = a / L` гиперболасына түседі — екі есе қысқа ішек бір октава жоғары дыбыстайды. Бұл — Мерсенн заңы (1636), ал пернелерді ішек ұзындықтарының қатынасы ретінде Әл-Фараби «Музыканың ұлы кітабында» сипаттаған. Домбыра болмаса — гитара не тартылған резеңке жарайды.

Әлсіз деректерді Zerde әлсіз деп атайды. Оң жақ төменгі бұрышта тек QaltaLab тәжірибелері мен ғылыми әдіс туралы жауап беретін чат бар.

## Шектеулер

- Нәтиже құрылғыға — микрофонға, динамикке, камераға, экранға — және шу мен жарыққа байланысты. Сондықтан QaltaLab `R²` көрсетеді және деректер аз болса, ашық айтады.
- «Сенің есту қабілетің» мен «Камерамен тамыр соғысы» — білім беру тәжірибелері, **медициналық диагностика емес**.
- Интернет керек; мессенджерлердің ішкі браузерлерінде камера мен микрофонға рұқсат жиі өшірулі.
- Пилоттық іріктеме шағын (n = 29).

<summary>Для разработчиков · Әзірлеушілерге</summary>

Сайт статический, без сборки и зависимостей: HTML, CSS и JavaScript. Серверные функции — `api/zerde.js` (Groq) и `api/class.js` (Supabase) на Vercel; ключи `GROQ_API_KEY`, `SUPABASE_URL`, `SUPABASE_KEY` — в переменных окружения.

```
js/lab.js         движок опыта: пять шагов, результат, PNG и CSV
js/labs/*.js      десять опытов, по файлу на опыт
js/predict.js     рисунок-предсказание и сравнение с данными
js/sound.js       спектр и поиск тона по гармоникам
js/class.js       общий график класса · js/qr.js QR-код без библиотек
js/fit.js         R² и автоподгонка · js/chart.js графики
js/zerde.js       разбор результата · js/zchat.js чат
js/orn.js         казахские орнаментальные мотивы
js/facts.js       все цифры сайта: статистика, PISA, пилотный тест
api/              zerde.js → Groq · class.js → Supabase
tools/            проверка цифр README и сборка инфографики
```

```bash
node --test tests/core.test.mjs     # 16 тестов логики
node tools/check-facts.js           # цифры README совпадают с js/facts.js
node tools/make-readme-assets.js    # пересобрать инфографику
```

</details>
