# Принятые решения (не переоткрывать без пользователя)

## Честность
- Никаких выдуманных цифр, цитат и внедрений. Все числа — из `js/facts.js`; README сверяет `tools/check-facts.js`. В README нельзя писать проценты, которых нет в facts, и приписывать функциям причины, которых нет в данных.
- Офлайна нет — не писать «работает без интернета». Service worker сознательно не добавлен: после выкладок у зрителей застревала бы старая версия.
- «Твой слух» — не «слуховой возраст» (не откалибровано); «Пульс камерой» — не медицина.
- Бутылка — резонатор Гельмгольца. 967 школ — кабинеты за один 2024 год.
- PISA 2022 (ОЭСР): базового уровня по естественным наукам достигают 55% (ОЭСР 76%) — дословно из Country Note. Средний балл 423 на странице только на графике — не используем.
- Аль-Фараби: только «описывал лады как отношения длин струны (9/8, 4/3)». Место рождения спорное — не писать.
- Пилот n = 29 — «участники», не «школьники»: возраст анкета не фиксировала. Самооценка, а не исследование успеваемости.
- Пример данных везде подписан как пример (шапка, #/demo, #/class/demo).
- «Голос учителя» (`facts.teacher`) — только настоящее интервью с согласия; до тех пор блок скрыт.

## Безопасность и данные
- Громкость в опыте со слухом ограничена `MAX_GAIN = 0.08`.
- Измерения считаются на устройстве; на сервер — только числа (Zerde) и точки с кодом класса. Имён нет.
- Ключи только в переменных окружения Vercel. Ключ Groq после хакатона заменить (попадал в переписку).
- Удаление данных в Supabase через инструменты Claude отклоняется системой разрешений — пользователь удаляет сам в SQL Editor.

## Продукт
- Плохой `R²` не блокирует разбор: слабый результат доводится до вывода («нужна повторная проверка»). Отрицательный `R²` пишется словами («ниже 0»).
- Смена языка или темы посреди опыта не сбрасывает замеры.
- «Физика домбры» — только главная карточка раздела «Опыты»; шапку и остальной сайт под неё не перестраивать.
- Выбросы на графике класса — дальше 3 устойчивых сигм **и** дальше 20% от кривой: разница между людьми — не ошибка.
- Знаки-достижения выдаются за научный результат (открытый закон), а не за клики.

- Орнамент разный по разделам (10 мотивов в `js/orn.js`), не один и тот же везде. Без смайликов в README.
- На карточках опытов — SVG-сцены (`js/art.js`), не стоковые фото.
