# Проверки QaltaLab

Всё запускается из корня проекта; результаты (скриншоты, профили Chrome, тестовый звук) — в `tools/qa/.out/`, в git не попадают. Нужен Google Chrome.

| Скрипт | Что проверяет |
|---|---|
| `i18n-check.mjs` | все русские строки в `js/**` переведены на казахский (код ошибки, если нет) |
| `serve.mjs` | локальный сайт на http://localhost:8766; `/api/class` — настоящий, если заданы `SUPABASE_URL` и `SUPABASE_KEY` |
| `full-audit.mjs` | 10 опытов от вопроса до сравнения серий, листы урока, пример, класс, оба языка, обе темы, телефон и компьютер, ссылки |
| `features.mjs` | тур «60 секунд», знаки-достижения, «Мои классы», QR на листе урока |
| `class-e2e.mjs` | учитель создаёт класс → ученик по `/c/КОД` проходит «Физику домбры» на звуке щипков → точки на экране класса (создаёт настоящий класс в базе) |
| `make-pluck.mjs` | генерирует `pluck.wav` — щипки струны для `class-e2e.mjs` |
| `readme-phones.mjs` | снимает скриншоты телефона для README с живого сайта |

```bash
node tools/qa/i18n-check.mjs
node tools/qa/serve.mjs                              # в отдельном терминале
node tools/qa/full-audit.mjs                         # против локального сайта
BASE=https://qaltalab.site/ node tools/qa/full-audit.mjs   # против живого
```
